## HP-08: Stage B3, first-iteration audition (▶) and lazy thumbnails
**Owner:** Misty · **Size:** M · **Depends on:** HP-07 · **Phase:** C
**Spec:** plan sections 8.4, 8.5, 12 (B3).

**Goal.** ▶ on a row **turns the circuit on and plays it live**. Nothing more.

**Scope.**
- If the row is not the live patch: load it (undo point, **no confirm**: it is a play gesture) and start live playback the same way the user normally turns the circuit on. If it is already live: only start playback. **No test note is injected, no offline render.** If nothing sounds (no MIDI module, no sequencer, no drone), that is acceptable.
- Works in the plugin (native engine plays), so ▶ shows there.
- **Thumbnails:** a flat placeholder until drawn; draw lazily the first time a row/folder is opened (no ahead-of-time bake). Design for a later `.reapeaks`-style cache folder (HP-16) by keeping the thumbnail function pure (patch/audio hash in, image out).
- Keep the shared 5 s worklet startup timeout as legacy where the engine start path already uses it; do not add new timers.

**Out of scope.** Offline render, MIDI-module preview notes, a dedicated preview variation, buffer cache (all HP-16). MIDI boundary: do **not** use `vmNoteOn`.

**Acceptance criteria.** ▶ on a not-live row loads it (single Ctrl+Z restores) and starts audio; ▶ on the live row only starts playback; a patch with a sequencer audibly plays; a patch with no source stays silent without errors or spinners; no polling/timers added; hosted site shows ▶ only if the engine can run there (else hidden, state which).
