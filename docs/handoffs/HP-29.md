# HP-29: Metamodule GL ghost plates

Status: ready, HELD. Do not serve until Argi confirms the symptom and asks for it. After release-readiness (Argi: metamodule last).
Source: MasterBot, 2026-11-27, from reading the code. Symptom still needs Argi's confirm.

## Symptom (to be confirmed by Argi)

On Root, the inner modules of a metamodule show as GL ghosts. Inside a metamodule, the Root modules show on top.

## Suspected root cause

Commit `e0d742dd` (2026-11-24, module display rewrite) dropped the `el.hidden` skip in the GL chrome rebuild, so the GL layer treats view-hidden (metamodule) modules as viewport-asleep and keeps drawing their cached plates.

Line numbers below are approximate; confirm them before editing.

## Fix

1. `public/node-graph-gl-graph.js` (~171-179) `nodeGraphGlGraphCollectPlateAndDisplays`: skip view-hidden nodes (`el.hidden` or `!nodeGraphModuleShouldBeVisible(node)`). Keep cached plates only for viewport-asleep nodes.
2. `public/node-graph-gl-graph.js` (~1382-1397) `nodeGraphGlGraphFillChromeForNode`, workspace path: don't replay the chrome cache for view-hidden nodes, but keep the cache for when they're shown again.
3. `metamodule-core.js` (~248-315) `nodeGraphSyncMetamoduleVisibilityToDom` / `nodeGraphRefreshMetamoduleViewDom`: after `hidden` flips, force a full plate and chrome rebuild plus present (`public/node-graph-gl-graph.js` ~267-280 RebuildPlatesFull). Incremental "just woke" rebuilds don't drop plates that are already meshed.
4. Add comments: hidden is not the same as viewport-asleep.
