# HP-28: Drag-out recording (IDEA STAGE, not queued)

Status: idea only. Argi hasn't picked it. Don't hand it off until he does (INDEX row N-10).
Source: MasterBot, 2026-11-27. Related: HP-25 (No Smoothing spectral effect), HP-26 (Additive Resynth), HP-27 (Additive Grid mode).

## Goal

After recording in Sandbox, the user presses on the recorded waveform and drags it out onto the graph. When it's dropped, a menu at the drop point offers:

- (a) **Add Sample Player**
- (b) **Add STFT Resynthesis** module and chain
- (c) **Add Additive Resynthesis** module and chain (HP-26)

Each option creates the module or modules at the drop point, preloads them with the recording, and wires them in.

## Notes for later

- No tooltips. The menu is event-driven, with no timers or polling. Usual UI policies apply: no hover effects, no animations, no hand cursor, phone friendly.
- Labels stand on their own. Module chains come from the module definitions; don't hardcode them in the menu.
- (b) and (c) depend on HP-26 and on an STFT Resynthesis module existing. Offer only the options whose modules exist.
