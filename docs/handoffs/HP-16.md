## HP-16: Robust audition, instrument modules on the MIDI module, peaks cache
**Owner:** Moth (engine/offline) + Misty (UI) · **Size:** L · **Depends on:** HP-08 · **Phase:** E
**Spec:** plan sections 8.5, 11.3 to 11.5, 12 ("Later stages"); Argi t3405 #12.

**Scope.**
1. **Basic instrument modules** (promised, never scheduled): pitch/gate/velocity instrumentation **on the MIDI module** (it provides DAW playability and the wires preview needs). The MIDI module is the instrument input; it may be absent. Hard MIDI split stays: preview notes go **through the MIDI module**, never `vmNoteOn`.
2. **Robust audition:** reuse Render Sample's offscreen path so the live patch is untouched: `nodeGraphBuildLivePlanForPatch(patch)` (`node-graph-live-plan-runtime.js:~80`, currently unreferenced, `visualSinks: []`), a quiet `onMessage` on `createNodeGraphLiveWorkletNode` (`node-graph-live-runtime.js:~3679`), a shared helper pulled out of `renderNodeGraphAudio` (`node-graph-render-output.js:~84`; the riskiest edit, its own stage), event-only waits (`nativeGraphStatus`, `processorerror`, `OfflineAudioContext` completion), keep the 5 s `nodeGraphLiveAwaitStartup` race as shared legacy, play through the native ear protector on an Explorer-owned `AudioContext` created on a user gesture, cache the buffer per row, a **dedicated preview variation** idea for reliable preview sound. Do **not** swap the live patch in and out as a fallback. Measure one bounce and write the number into the plan.
3. **Peaks cache folder** in the style of REAPER's `.reapeaks` for thumbnails.
4. Info line (plain text) that modules needing main-thread feeds (Music Player, mic input, code boxes, host CV feeders, portals) are silent or wrong in an offline preview.

**Acceptance.** Preview plays a note through a patch that has a MIDI module without touching the live patch or its undo history; a patch without one stays silent gracefully; thumbnails come from the cache on second open.
