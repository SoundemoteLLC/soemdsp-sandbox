## Goal

Inside a metamodule, the user chooses one inner module. The metamodule's face shows that module's display, drawn by WebGL straight from the child's own display data. This is the module face, not the Command Center, so APP_POLICY §26 (no WebGL in the Command Center) does not apply.

No DOM cloning. Updates only when the child redraws (event-driven). This replaces the old `metamodule-display-mirror.js` approach; retire that file.

Usual policies: param definitions are the single source of truth, 1:1 pixel-honest displays, no hover effects, no animations, no tooltips, low cognitive load.
