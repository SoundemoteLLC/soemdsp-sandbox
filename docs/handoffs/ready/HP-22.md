# HP-22: One debug window on G

## Problem
Pressing **G** opens the old "evidence" / other debug window. The main CPU/RAM/GPU debug window doesn't toggle with G.

## Goal
- **G** toggles the main CPU/RAM/GPU debug window, and only that one.
- Remove the evidence window. If anything in it is still useful, move it into a collapsible subsection (sub-window or tab) inside the main debug window. Drop anything that's redundant or dead.
- There must be no second floating debug window left.

## Rules
- Don't worry about legacy compatibility. The app is still in heavy development.
- Events only, no timers or polling. If the panel already samples stats, keep its existing mechanism.
- No hover tooltips, no hand cursor, and labels must stand on their own. Keep the low-clutter UI.
- Report what you kept, what you moved, and what you removed.

## Also in this round: sincos negative amplitude bug
- If sincos Amplitude is set to -0.5 (or any negative value), the display correctly inverts, but the audio treats it as 0 amplitude (silence).
- Fix it so a negative amplitude outputs the inverted signal at that magnitude, matching the display.
- Find where the value gets clamped to 0 or rectified (DSP, wasm bridge or reader). The param definition is the only source of limits, so don't hardcode clamps.
- If the wasm changes, say so, so the 8766 server gets restarted.
