## HP-07: Stage B2, the Preset Explorer UI
**Owner:** Misty · **Size:** L · **Depends on:** HP-01, HP-06 · **Phase:** B · **Unblocks:** HP-08
**Spec:** plan sections 8.1 to 8.3, 8.6, 12 (B2), 13, 14.

**Goal.** The 📄 Command Center page becomes the Preset Explorer: one searchable list of factory and user presets with folders for variations. A DOM menu panel (same status as the paper-page panel it replaces).

**D-P2 (decided t449u).** User presets are treated exactly like factory presets and organized with them seamlessly. The only differences: a different save location, a visible indicator that a row is a user preset, and a filter for Factory / User / Both.

**Layout.** (1) **Search** (text filter on name, folder, author, nothing else). (2) **3-way switch Both / Factory / User** (D-P2). (3) **One list**, folder-style: factory (from `patches/index.json`) and user (from `/api/patches`) organized seamlessly and interleaved by name; each row has the name, a visible user/factory indicator, a small thumbnail placeholder, and a ▶ (preview only in HP-08; ▶ never loads the live patch). (4) A preset with variations is a **folder** you open; children are its variations with the same row anatomy. (5) Buttons: **Save Preset, Save Variation** (two separate buttons), **Load, Remove, Rename**. The app's main save button does **not** change.

**Behavior.**
- Tapping a row only **selects** it.
- **Load** and **overwrite** (Save onto an existing file) use an inline confirm on the same button ("Confirm Load" / "Confirm Overwrite") that clears on selection change, panel close, or commit **events, never a timer**. Before a Load call `recordNodeGraphHistory()` so one Ctrl+Z restores the previous patch. Load goes through `commitNodeGraphScript(text)` (= `commitNodeGraphPatch(loadNodeGraphPatchFromScript(text), {status})`); the commit listener wakes everything. Do not pass `resetEditorView` (framing is the Patch View box's job; `frameNodeGraphPatchViewAfterLoad` already handles it).
- **Save Preset** writes the live patch as a user preset (overwrite if a user preset is selected; `Untitled N` if unnamed). **Save Variation** writes the live patch as a variation of the selected/open parent (auto-numbered if no name; parent becomes `Untitled N` first if unnamed). Factory rows are read-only: Remove/Rename disabled, Save Preset offers "Save as user preset".
- **Remove** deletes a user preset and its variations folder (confirm) or a variation (confirm). **Rename** renames a preset with its folder together, or a variation.
- Hosted/static site: **load-only** (hide Save, Remove, Rename). Plugin: full, via HP-06b.
- After a load: `setNodeGraphCurrentSavedPatch`, `nodeGraphRefreshServerPatchFileBaseline`, `syncNodeGraphHeaderPatchTitle` (as the normal load flow does).
- Phone-friendly: one column, 44 px rows, ▶ is a 44 px target, no hover, no `title=`.

**Files.** New `public/node-graph-preset-explorer.js`; uses HP-06's `node-graph-preset-store.js`; entries in `node-graph-unified-window.js` / `node-graph-floating-windows.js` (the `pages` registry entry now points at the Explorer); `index.html`, `perform.html`, `styles.css`.

**Acceptance criteria.** Browse factory + user together; the 3-way switch filters; search filters; open a folder; Save Preset / Save Variation round trip to disk and appear in the list; Load is one confirm + one undo step; Remove/Rename keep preset and variations folder together; hosted build shows no write buttons; Argi's retest list includes "load a patch with gradients (HP-04) and see them restored". `?v=` bumps; no timers.
