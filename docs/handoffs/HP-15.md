## HP-15: 50 generic plugin parameter slots
**Owner:** Moth (plugin repo + sandbox) · **Size:** L · **Depends on:** HP-04 / HP-10 (so there is something to assign) · **Phase:** E
**Spec:** plan sections 4.4, 12 ("Later stages"), 15; Argi t3405 #9 and #15.

**Goal.** Register **50 generic plugin parameter slots** that can be assigned to **sliders, Mutators, or gradient positions**, so no feature needs its own host-visible parameter. Gradient position is never automatable **inside** the circuit builder (no cable into it); host automation comes only through these slots.

**Today.** Slots are Knob `pluginId` 0 to 31 (`public/modules/knob/knob-face.js:62`), plugin param ids 1000 to 1031 (`soemdsp-sandbox-audioplugin/src/engine/engine.cpp:194`), `paramsCount()` from `engine->patch.params.size()` (`plugin-clap.cpp:469`).

**Scope.** Raise to 50 generic slots (decide whether Knob `pluginId` is subsumed or kept as one assignable target type); an assignment model saved with the patch (slot → target {param | mutator axis | gradient position}); UI for assigning (Gradients page row, Mutator overlay, parameter context menu; no tooltips); `plugin-host.js` and the native engine both route slot changes; the existing 32-slot patches keep working (migration, or alias the old ids). Preset/variation load must reset or keep assignments by a stated rule (ask Argi).

**Acceptance.** In REAPER, 50 slots show in the host; assigning a gradient position to a slot and automating it moves the effective params; session recall restores assignments; old patches with `pluginId` 0 to 31 behave as before; plugin builds on Windows CI (tag rules in the plugin repo).
