## HP-21: Display trail/ghost defaults
**Owner:** big AI · **Size:** S · **Depends on:** after HP-03 (after HP-20) · **Phase:** A

Hypersaw's display defaults to high trail and ghosting; both should default to 0. Rounding Error is worse: it does not expose a Trail control, and Ghost at 0 still shows burn, probably because a hidden trail is set high (Argi t494u).

**Fix.** Expose Trail wherever there is Ghost. Default both to 0. Ghost 0 plus Trail 0 means no burn at all. Parameter definitions stay the source of truth for limits.

**Included targets** (quick search of display defaults / control schemas; no deep reading):
- Shared bag `nodeGraphScopePhosphorLookDefaults` in `public/node-graph-module-scope-defaults.js` is **trail 0.3, ghost 0.25**. `PhosphorResidual.DEFAULT_TRAIL` is 0.3 and `DEFAULT_GHOST` is 0.25. Most phosphor faces inherit these.
- Display types with nonzero defaults (they inherit that bag unless a per-type bag already says 0): `hypersawBurn` (Hypersaw, Robin Supersaw, Ping Pong Delay Lines, and any other module on this face), `lineBurn`, `scope2d`, `scope1dTrace`, `scope2dTrace`, `videoscopeBurn`, `phosphorLight`, `xyPad`, `vectorRgbFace`, `gradientVectorscopeFace` (also has leftover fallbacks 0.88 / 0.45 if Residual is missing), `arpKeysFace`, and `dot`. Confirm `numberReadout` (it exposes Trail and Ghost; the Value LCD defaults bag is already 0).
- Hidden trail: `roundingErrorFace` fields are `fadeTime` and `ghost` only — no Trail control. That is the Rounding Error case; expose Trail and default both to 0.
- Already 0 (leave as is): Value oscilloscope and Value LCD (`ghost: 0`, `trail: 0` in their defaults bags).

You figure out whether a shared-default change covers the list, or whether some faces need their own 0. Report which types you changed. Saved patches may keep their stored values; say what you did.

**Acceptance (one line each).**
1. A new Hypersaw and a new Rounding Error start at Trail 0 and Ghost 0, with no burn.
2. Trail is exposed wherever Ghost is, including Rounding Error.
3. Ghost 0 + Trail 0 means no burn on every included display; the other listed types also default to 0 (or a shared change covers them).
