A new 'Additive Grid' mode in the existing Additive generator that makes the blocky 'FFT as additive' sound:

- Partial frequencies snap to a strict grid at bin centers (multiples of sample rate / FFT size).
- Amplitudes update only once per frame, stepped with no glide.
- An optional hard frame-boundary mode with no crossfade between frames.
