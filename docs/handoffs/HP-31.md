## Goal

The user lays out several inner displays on the metamodule face like a mini canvas, using the same WebGL drawing path introduced in HP-30 (straight from each child's own display data, no DOM cloning, event-driven updates when a child redraws).

Usual policies: param definitions are the single source of truth, 1:1 pixel-honest displays, no hover effects, no animations, no tooltips, low cognitive load.
