## HP-02: Stage A1, one param-offset provider list (+ plugin-host reads effective params)
**Owner:** Moth (Misty authored the design) · **Size:** M · **Depends on:** nothing · **Phase:** A · **Unblocks:** HP-03
**Spec:** `docs/MODULE_GRADIENTS_AND_PRESETS_PLAN.md` sections 4.4, 12 (A1), 14. **Approved by MasterBot** for `node-graph-live-plan-runtime.js` under conditions below.

**Goal.** Make "effective param" computed in exactly one place. Generalize `pitchMutatorApplyLiveParams` into an ordered **provider list** (gradients first, Pitch Mutator second) with **no change in behavior** for the Pitch Mutator.

**Scope.**
- Today: `root.pitchMutatorApplyLiveParams = applyLiveParams` (`public/node-graph-pitch-mutator-overlay.js:931`) is called from `public/node-graph-live-plan-runtime.js:191` and `:333`; `applyToBase` (overlay ~290) is a second consumer. Introduce e.g. `registerNodeGraphParamOffsetProvider(fn)` + `applyNodeGraphParamOffsets(node, params)` (name to taste) in `node-graph-live-plan-runtime.js` or a tiny new file loaded before it; the Pitch Mutator registers itself; call sites call the list.
- **Plugin.** `public/plugin-host.js` diffs `node.params` after page edits (`copyParams`, ~lines 201 to 232) and posts `param` events to the native engine. A provider offset is not in `node.params`, so the diff would miss it. Make the diff read the **effective** params from the same provider function. Keep the plugin host's existing legacy timers as they are.
- After a value change that came from a provider, call `nodeGraphGlGraphNoteValueChrome(id)` so GPU-drawn controls repaint (call, do not edit that file).

**Conditions (MasterBot's).** Parameter values only. No camera or cull code. Do not edit `node-graph-gl-graph.js` or the other listed files.

**Out of scope.** Gradient data (HP-03), native tables (HP-11).

**Acceptance criteria.**
- Pitch Mutator behaves identically: `scripts/test_pitch_mutator_engine.mjs` passes unchanged; load `tests/fixtures/view-real-acoustic-bass.json` and confirm the same effective params before and after (add a headless script that builds live params for that fixture with the old and new path and diffs them).
